# 长生录 · 凡尘修仙

这是一个可持续游玩的单人文字修仙沙盒。世界参考忘语《凡人修仙传》的凡人入道、灵根、境界、资源经营和谨慎历练氛围；地点、人物、故事与数值规则为本项目原创。无限复活是本游戏模式的设定。原作信息可参见[起点的忘语作者介绍](https://acts.qidian.com/2022/221019/index.html)。

## 开始游玩

在项目环境中运行 `python seed.py`，重启实际提供服务的进程。种子导入按标题跳过已有条目，不更改已有世界。Web 聊天页与 Telegram 均可输入 `/scripts`，选择「长生录 · 凡尘修仙」。

你从五行杂灵根、炼气一层开始，持有12灵石、3株灵草和1枚回春丹。没有主线任务、终局、寿元倒计时、每日行动点，也不会在离线期间自动遇险。想一直做散修或只经营丹药生意都可以。

- `修炼`：在洞府静坐60分钟，当场看到修为增量。
- `地图`：显示九个地区及连通道路。可输入 `去青岚谷`，按道路逐段移动。
- `采药`、`挖矿`、`炼丹`、`炼器`：到对应地点反复生产。
- `卖灵草`、`买回春丹`、`卖养气丹`：在坊市交易。
- `突破`：修为与灵石充足时，在洞府主动尝试。
- `丹方`、`储物袋`、`复活规则`、`怎么玩`：免费查询。
- `/status`、`/resume`：查看并恢复存档；编号和按钮也能执行行动。

默认回复聚焦小说式正文，不自动附上菜单、规则说明、完整状态或存档提示。需要菜单时输入 `/guide` 或 `/options`，查看角色用 `/status`；问境界只回答境界，问储物袋只展示物品。

这些基础指令与按钮无需 AI 服务即可游玩，本地描写覆盖修炼、炼丹、采集、历练等动作，连续修炼轮换不同感官描写。配置 AI 时，已有 DeepSeek Harness 以提交后的结果和最近两次经历为依据润色，不重复介绍世界。自由描述继续通过意图翻译与交流接口处理。AI 不决定境界、资源或复活结果；正文生成失败会返回已保存的本地描写，完整规则回执仍在行动记录中。

## 地图与养成循环

洞府连接青岚谷、青石坊市和青岚宗山门；坊市连接百草丹房与听火器坊。青岚谷通向雾隐荒山，荒山连接赤铁矿脉与落星遗迹，矿脉也通向器坊。所有地区从开局即可沿道路抵达，不需要先完成任务。

| 地点 | 可反复进行的活动 |
| --- | --- |
| 无名洞府 | 修炼、主动突破、扩建聚气阵 |
| 青岚谷 | 每15分钟采得2株灵草 |
| 青石坊市 | 灵草、丹药与护身符交易；结交许掌柜 |
| 百草丹房 | 3灵草 + 2灵石炼制养气丹 |
| 听火器坊 | 2灵铁矿 + 2灵石制作护身符 |
| 青岚宗山门 | 论道、自由加入或退出外门 |
| 雾隐荒山 | 75%成功率历练，获得灵石与修为；存在伤害 |
| 赤铁矿脉 | 每15分钟开采2块灵铁矿 |
| 落星遗迹 | 50%成功率探险，收获更高，失败受24伤害 |

采药、采矿没有资源枯竭限制；低资源存档仍可以采药出售重新积累。材料不足、地点不符或修为不足的行动会解释原因，不扣材料、不推进时间。查看玩法和闲聊同样不消耗时间。

## 境界与长期成长

炼气共十三层，之后依次为筑基、结丹、元婴、化神、炼虚、合体、大乘，各分初、中、后期。再往后的游戏成长表示为「渡劫后 · 道行第N重」，继续积累和突破，不触发结束。

令 `rank` 为从0开始的境界档位：

- 一次修炼增加 `10 + 2 × rank + 2 × 洞府等级` 修为。
- 当前突破需要 `30 + 15 × rank` 修为和 `3 + 2 × rank` 灵石。
- 突破成功率70%；每次先扣灵石，成功扣除所需修为并提升一档，失败损失所需修为的五分之一（整数）和5气血。溢出修为保留。
- 每次成功突破气血上限增加2，上限100；境界与修为不设通关上限。
- 养气丹增加 `30 + 3 × rank` 修为；回春丹恢复最多15气血。
- 炼丹和炼器每次分别增加1点熟练度，初始产出1份，每10点熟练度多产出1份。
- 洞府从0级开始，升级需要 `20 × (等级+1)²` 灵石与 `2 × (等级+1)` 灵铁矿，每升一级永久提高每次修炼收益2点。

荒山成功时受3伤害，失败受12伤害；遗迹成功时受6伤害，失败受24伤害。成功均有奖励，失败没有奖励。护身符在每次历练受击时自动消耗1张、抵挡8伤害。调息可花15分钟恢复2气血，不耗物品。

## 无限复苏与存档

气血归零后，轮回印立即将你送回洞府：

1. 境界、剩余修为、技艺、洞府、宗门身份、人情和其他物品全部保留。
2. 扣除当时随身灵石的10%，向上取整；0灵石也能复活。
3. 恢复全部气血，增加60分钟和一次复活记录。
4. 停止当前复合计划剩余动作，等待玩家重新选择。

复活次数不设限制。世界保持 `running`，角色保持 `alive`，不写结束时间。复活与该次动作的材料消耗、检定、结果、位置及行动日志在同一 SQLite 事务内保存；保存失败则一起回滚。

## 实现边界

目前是九个手工编写地区构成的开放地图、可重复的资源与成长系统，尚未提供无限生成地图、离线挂机、多人宗门、自由建造或 AI 自行创造规则。这里的“无限”指持续成长和复活，没有剧情终点。

`narrative.sandbox = "cultivation"` 选择该模式。DSL 禁止此模式带剧情锚点、结局或一次性交互；`cultivation_action` 只允许白名单动作。旧剧本的结局和死亡规则保持原语义。`days=1` 仅兼容旧剧本元数据，沙盒生命周期不依据它终止，状态页显示实际修行天数。

主要实现为 `app/engine/cultivation.py`、`cultivation_story.py` 与共享的叙事事务引擎；无需迁移 SQLite 表。离线回归：`python tests/cultivation_test.py`。

## 主动叙事

按 [Narrator Contract](narrator-contract.md) 运行：九个内置地区各有可验收的环境/NPC 段落，默认独立于玩家消息推进。遇到介入点停笔，不自动提问或展示数值。`/pause` 暂停，`/stream on` 恢复；`/pass` 表示暂不介入，`/autonomy` 查看或分别调整 World、Player、Narrative 参数。角色的重大决定与资源变化仍须玩家授权。

## 按需补全功法

在洞府询问“功法”，可研习《引露诀》《照烬诀》；具体能力由 AI 在固定预算内生成并登记，学会后不重新生成。用“吐纳蓄灵”恢复灵力，“用引露诀在火纹试法石试法”观察能力碰撞。研习须真实 AI，已学规则的明确动作可离线执行。灵力首次初始化为空，不改动既有成长。详细边界、候选重试与运行方式见 [动态功法与试法](runtime-rules-play.md)。
