## 已发现并修复的问题

1. 第一次木楔撑门：模型只调用 introduce 取出木片，却在正文写成已经撑门。现在取出材料的回执明确区分未执行的用途，并返回物件 ID 与属性；Skill 要求继续执行 manipulate。随后真实运行已观察到完整计算链和门上安排的持久记录。
2. 普通动作后反复附加阿禾扶苗、掌柜站着、布角被风掀起。已限制一段最多一个新增场景事件，并要求没有变化的旁观人物不必重写。
3. 借炉对话补出与 `lit=false` 冲突的炉火、把异地后院当作眼前可见场景。新增候选事实核对，同时检查正文和 scene 记录；冲突最多重做一次，仍不一致不落库。
4. 保留旧版 CLI 回归时，原测试按标题包含“长生录”和固定菜单序号选错了新版本。回归现按确切旧版标题和实际剧本列表选择；新 Skills 版另有独立入口测试。
5. 自主片段曾只读取上下文，没有登记事件便返回正文，被提交检查拦下。现在明确区分 WORLD 与 PLAYER 主持任务，世界片段必须登记场景；格式错误最多从原快照重试一次，不能跳过检查。玩家新输入会取消尚未提交的自主候选。
